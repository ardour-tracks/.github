# Ardour - A Session for Recordings You Made

![Ardour with one session of recordings the user made](https://manual.ardour.org/images/editor_map.png)

## Product Snapshot

Ardour is a multitrack recorder and editor for sound you already have the right to use. You arm a track, record, or import a file you made, then move regions on a timeline. The mixer sets levels. Nothing here downloads a catalog, and a commercial recording you do not have rights to is not a track to drop in.

The session folder holds the audio and the edits. If you move one piece and not the other, the timeline goes quiet. Keep the folder together. Export a WAV or similar file when someone needs a single playable result. Listen to that file outside Ardour before you delete any take.

## Mount and Burn Toolkit

| Task | What you get |
|---|---|
| Record | A take from an input you chose on this PC |
| Import | Files you already have and may use |
| Regions | Pieces of those files on a timeline |
| Mixer | Levels per track you recorded |
| Export | A new audio file, not a replacement of the takes |
| Session | A folder you can copy as a spare |

A click and a talkback are optional. The first session does not need a large interface. A working input device matters more than a plugin list.

## Deep Dive

Create the session on a disk with room for audio, not on a nearly full system drive. Record ten seconds. Play them back. If the track is silent, check the input before you reinstall anything. Save, then export a short file and open it in an ordinary player.

Plugins can wait. A session you cannot reopen is a worse problem than a plain mix. Copy the session folder before you try a destructive edit you do not understand. Ardour will not strip a watermark from someone else's master, and it should not be asked to.

## Adoption Paths

Ardour fits a song, a podcast, or a class recording you are making yourself. It fits a desk with one interface and headphones. It does not fit a hunt for stems you do not own, and it is the wrong place to "remove" protection from a file that will not open.

## Install Walkthrough

Prerequisites: An input you can hear, a disk with free space, and audio you are allowed to record or import.

1. Install Ardour and create a session in a folder you can find later.
2. Record or import one short clip you made.
3. Play it back and set a level you can hear.
4. Save the session, then export a new file.
5. Listen to the export outside Ardour. Keep the session folder.
